# HAIKAI

PS1 畫風的蒸氣龐克恐怖搜打撤遊戲（計畫代號 sodache）。引擎：Godot 4.3。

## 怎麼打開

1. 下載 [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/)（標準版，不需要 .NET）。
2. 打開 Godot，按「匯入」，選這個資料夾裡的 `project.godot`。
3. 按右上角的 ▶（或 F5）開始玩。

## 操作

| 按鍵 | 動作 |
|---|---|
| WASD | 移動 |
| 滑鼠 | 看 |
| Shift | 衝刺（消耗體力） |
| Ctrl / C | 蹲下（可以爬進管道） |
| 空白鍵 | 跳；在梯子上按會跳離梯子 |
| W / S（貼著梯子） | 爬上 / 爬下 |
| E | 撿起物品、互動（拉桿、櫃子） |
| G | 丟下最後撿的物品 |
| F | 開關提燈 |
| 左鍵 | 使用武器 |
| Q | 使用消耗型強化（腎上腺素針、貓眼藥水） |
| R | 使用背包裡最後撿到的可用物品（牛奶、音叉、隨身聽、洗衣粉、鑰匙、沙漏…） |
| M | 麥克風開 / 靜音（多人時） |
| 左鍵（自己出局後） | 切換觀看的隊友 |
| Esc | 放開滑鼠（點畫面再抓回來） |

## 多人連線（最多 8 人）

1. 一個人當主機：在倉庫畫面按「**建立房間**」。
2. 其他人在「加入房間」左邊的框輸入主機的 IP，按「**加入房間**」。
   - 同一個 Wi-Fi / 區網：用主機電腦的區網 IP（例如 `192.168.x.x`）。
   - 不同地方：主機要在路由器開 **UDP 24500** 埠轉發，再給朋友外網 IP；或用 Radmin VPN / ZeroTier / Tailscale 這類虛擬區網軟體，用它給的 IP。
3. 人到齊後主機按「開始」，全員一起進場。

- 每個人帶自己倉庫的道具進場，撤離時各自結算自己背包的東西。
- 物品是共用的：誰先撿到就是誰的。隊友死掉時背包會散落在地上，可以幫他撿回來。
- 任何人拉下鍋爐拉桿，全隊的升降梯都會通電，巨像也會為所有人醒過來。
- **近距離語音**：麥克風會自動開，只有附近的隊友聽得到你，而且**附近的怪物也聽得到**。按 M 靜音。死掉的人說話活人聽不到。
- 自己撤離或死掉後可以看隊友的視角，點左鍵切換；所有人都結束後一起看結算，回到房間可以再開一局。

### 多小隊對戰（PvPvE）

在房間裡按「**換小隊**」可以選紅、藍、黃、綠四隊（每隊最多 4 人）。大家都在同一隊就是合作；分成兩隊以上時：

- 各隊從地圖上**不同的地方**出發，彼此離得很遠。
- 槍可以**打傷別隊的人**（同隊不會誤傷，只有爆炸誰都炸），傷害是槍的傷害 ×1.2；玩家有 100 點生命。
- 別隊的人大衣是他們隊伍的顏色，頭上**沒有名字**；附近的語音大家都聽得到，包括敵人。
- 被打死的人背包會散在地上，誰都可以撿走。
- 結算時除了自己賺多少，還會列出各隊撤出的總金額排名。死掉以後只能看自己隊友的視角，隊友都結束了才能看別隊。

## 守墓者（階段 3）

多人時可以有一個人在房間裡按「**我要當守墓者**」。守墓者不進場，而是在「機房」用俯視視角操控整張地圖。

- 守墓者**看不到搜刮者本人**，只看得到他們發出聲音的位置（黃色圓圈）。搜刮者越吵（跑步、撞東西、講話），守墓者的能量越多。
- 三個能力：
  - **關閘門**（25 能量）：點地圖上的「閘」，會關 15 秒。每張地圖的門、鐵捲門、通風管道口都有閘門。
  - **斷電**（45 能量）：全場熄燈 20 秒，出口也停擺。
  - **放出怪物**（60 能量）：在點的位置放出撲燈蛾、擬態蟲、發條鼠群或假人（Tab 切換），不能離搜刮者太近。
- 勝負：每個搜刮者算 $250 的門檻。全隊撤出的錢低於門檻，守墓者就贏。守墓者贏了拿 $250，輸了也有 $50。
- 沒人當守墓者時（包括單人），由 **AI 導演**用同一套能力代打，但比較溫和。

## 地圖（階段 4）

每局從四張地圖隨機抽一張，不用解鎖。物品和怪物都跟地圖無關，哪張圖都可能出現。

**隨機延伸的地圖**：每張地圖中間是固定的主場景（任務、撤離點都在這裡），房間從主場景的門口每局隨機往外長：走廊、房間、大廳一間接一間，會分岔、繞回、走到死路。整張圖大約 170×190 公尺、60 個房間，每局都不一樣。
- 門有大門（大怪物也過得去）和小門（只有人過得去，可以當安全口袋），有些門守墓者關得起來。
- 離主場景越遠的房間東西越好，最深處可能有金庫。
- 每張地圖有自己的設施：
  - 工廠：熔爐大廳、輸送帶廠房、儲槽區、掛滿鐵鍊的房間、管線走廊。
  - 商場：百貨賣場（一排排貨架）、美食街、服飾店、玩具店、停車場、後場走廊。
  - 地鐵站：鋪著鐵軌的隧道、廢棄的側月台、員工休息室、塌陷區、淹水的隧道段、公共廁所、書報攤、塞滿東西的失物招領處（在最深處）。
  - 夢核：家具大三倍的巨人房間、通往牆上一扇門的樓梯、滿牆的門（其中一扇是真的白門）、家具都在天花板上的房間、掛著空白畫框的長走廊。
- **陷阱**（每張圖有自己的一套，加上到處都有的三種）：
  - 到處都有：捕獸夾（蹲下按 E 拆掉）、門口的絆線警報（跳過去或蹲下按 E 剪斷）、壓力板沙包。
  - 工廠：蒸氣噴口、漏電積水（斷電時安全）。
  - 商場：防盜感應門（帶著東西走過去會大響）、會倒下來的貨架。
  - 地鐵站：第三軌（有電時踩上去會被電飛，斷電時安全）、鬆脫的天花板（走到下面會掉灰、嘎嘎響，停留就塌下來）、票務閘門（站著推過去會大響，蹲下從橫桿底下鑽過去就沒事）。
  - 夢核：音樂盒（會把怪物引過來，按 E 關掉）、會吱吱叫的地板。
- 地圖變大，每局怪物改成 3～5 種。
- 所有連線玩家用同一個種子，拼出來的圖完全一樣。
- **黑暗鍋爐工廠**：高大的鍋爐廠房，兩側高架走道、兩條可以走的管線、蹲著才進得去的通風管道。北邊重啟主鍋爐，升降梯撤離。
- **午夜購物中心**：打烊後的兩層樓商場，中庭有乾掉的噴水池和兩座停擺的手扶梯，兩側商店有鐵捲門，後場通到裝卸區。
  - 先到二樓東北角的**配電室**推上總電源，再到裝卸區的貨梯撤離。
  - 商場自己也還在運作：鐵捲門會不定時自己落下 10 秒；廣播會突然響起，聲音會把附近的怪物引過去。
  - 中庭一樓是大怪物的地盤，商店和二樓比較安全（手扶梯太窄，大怪物上不去）。
- **廢棄地鐵站「末班車」**：封閉多年的地鐵站。一條長長的島式月台夾在兩條下沉的軌道中間，西端上方是售票大廳（閘門、售票機、站務室），靠兩座停擺的手扶梯下到月台。
  - 側翼的房間都開在軌道後方的維修走道上：要去搜刮就得穿過軌道（走平交道木板，或從軌道壁上的踏階爬上爬下）。
  - **末班車**：每隔幾分鐘，隧道深處會響起汽笛、月台邊的警示燈開始閃、車頭燈從黑暗裡越來越亮，右上角會寫是**南側還是北側**軌道，大約 10 秒後一列幽靈列車高速衝過整座車站。還在那條軌道上的人會被撞飛、重傷；被撞到的怪物也會受到重創（可以把怪物引到軌道上）。站在月台或軌道後方的走道上就安全。列車經過時有時會在月台上留下一件行李。
  - 先到月台東端的**號誌室**拉下總閘恢復供電，再到西端搭**維修電梯**撤離。恢復供電後燈會亮起來，但末班車會跑得更頻繁。
  - 手扶梯和售票閘門太窄，大怪物上不了售票大廳；號誌室是小門。
- **無盡的午後**（夢核）：太亮、太安靜的粉彩色房子，像小時候的家但大了好多。一條白色走廊連著客廳、室內遊樂場、餐廳、臥室和泳池間。
  - **清醒度**：右上角顯示，待在這裡會一直往下掉（泳池間掉得更快，背包裡的安撫物品掉得慢）。越低畫面越像夢，掉到 0 你就醒了：只能帶走一半的東西。
  - 走廊會循環，一直往同一個方向走只會回到原地。
  - **白色的門**：客廳和臥室衣櫃裡的白門會隨機把你送到另一個房間。
  - 這裡太亮了，提燈沒有意義，怪物隨時看得到你；臥室的門只有小孩的大小，大怪物進不去。
  - 到餐廳吹熄生日蛋糕的蠟燭，再回玄關從大門出去。

## 一局怎麼玩

1. **倉庫・改槍台**：像塔克夫一樣組自己的槍。選一把槍身（13 種：舊警用左輪免費，還有衝鋒槍、泵動獵槍、栓動步槍、工業釘槍、鋼弩、火焰噴射器、特斯拉線圈槍、捕鯨魚叉槍、磁軌炮、爆炸鴨發射器、圓鋸片發射器、泡泡槍），在槍口、槍管、瞄具、彈匣、槍托、下掛、彈藥、怪東西 8 個槍位裝配件（30 多種），右邊會即時顯示數據變化。改裝規劃是免費的，可以存成方案（最多 6 個），按「裝備」才會買齊缺的零件。另外最多帶 3 個強化。死掉會全部失去，活著撤離就能帶回來。
   - 每個人都有一把小刀（V），左鍵開槍、右鍵瞄準、R 換彈。子彈有限，要省著用。
   - 怪物有血量和弱點：小型、中型怪打得死，大型怪只能打到「崩潰」倒地一陣子，之後又會站起來。
   - 強化：腎上腺素針、彈簧鞋、鐵肺、夜視護目鏡、外骨骼背架、心跳偵測器、羽毛斗篷、兔腳幸運符、第二條命懷錶、貓眼藥水。
2. **搜刮**：每局先從 100 種物品裡抽出約 30 種當「本局物品池」，再隨機放 14 到 19 件。上鎖的櫃子要用小刀撬開（按 E 或 V，或用備用鑰匙），裡面東西比較好。背越重走越慢。
   - 有些物品能用（按 X），有些拿著就有效果：雨傘讓你慢慢落下、溫度計靠近怪物會變冷、音樂盒會讓哄睡的母親停下來。
   - **重物**一個人搬很慢，隊友站在旁邊一起抬才正常。**活的**東西會從手上溜走。**詛咒**的東西很值錢但會惹麻煩。
   - 巨像腰上有一顆鬆掉的螺栓（傳說），只有它排氣的時候才拔得下來。
3. **怪物**：每局從 20 多種怪物裡隨機抽 4 到 6 種（大型最多 2 隻），每局遇到的組合都不一樣。
   - **長頸觀察者**（大型）：高到能從牆後往下看。只看得到**會動**的東西，被它盯住 3 秒就會被抓走。停下來不動，或躲到屋頂、走道、二樓底下就安全。頭頂傳來喀喀聲就是它。
   - **蜈蚣列車**（大型）：跟火車一樣長，沿著固定的環狀路線全速衝過來，碰到就被輾死。路線每次都一樣，聽到地板在震就躲進旁邊的房間。每跑兩段會停下來休息一下。
   - **哄睡的母親**（大型）：沒有臉的巨大女人，哼著搖籃曲慢慢跟著你，被她抱住就死。她看到你在跑會加速；附近有音樂（音樂盒、隨身聽、音叉）她就會停下來聽。
   - **霧行者**：看不見，只會偶爾閃一下輪廓，跑得比你快。用粗鹽彈打到它或灑粉在它身上，它就會現形變慢一陣子，現形時才打得痛。它不靠近帶著冰的人。會乾咳。
   - **調音師**：會記住你們常走的路然後埋伏；會用隊友的名字在對講機講假話；被它追的時候會把你前面的門關上。任何聲音都會把它引走，聽到音樂會短暫錯亂。先跟隊友約好暗號。
   - **捉迷藏的孩子**（小型）：靠近時它會開始數數然後躲起來，旁邊一定有玩具。用提燈照到它就算你贏，會留下稀有的禮物；時間到它會來找你，被找到提燈會壞掉，而且它會大喊每個人的位置。
   - **迎賓員**：一直微笑跟在你後面。你一用跑的它就變臉，瞬間出現在你背後重傷你。對它按 E 回答問題，背包裡有東西給它看，它就會鞠躬離開；兩手空空回答會被打。
   - **回收員**：推著吱吱叫的推車撿走地上的東西，湊滿 3 件就擺成誘餌、躲在旁邊等人來拿。被它追的時候丟一件東西在它旁邊，它會收下然後放過你一陣子。
   - **發條鼠群**：一群發條老鼠，圍住你會一直咬，還會從背包叼走東西拖回巢裡。丟在地上的東西牠們會先搶；在牠們旁邊跳一下（落地的震動）就會嚇跑。
   - **假人**：只在沒人看著它的時候動，而且比你跑得快，被碰到會重傷倒地。盯著它就不能動，多人時可以輪流盯。關燈的話要很近才看得見它。
   - **撲燈蛾**：會飛向亮著的提燈，撲滅後尖叫，把附近的怪物引過來。關燈它就找不到你。
   - **擬態蟲**：偽裝成地上的寶物，撿起來會咬住你的手，幾秒內不能用武器和道具。仔細聽，它會輕輕滴答響、偶爾抽動。開一槍或用小刀戳一下，它就死了。
   - **剝皮獵犬**（2～3 隻一群）：比你衝刺還快。背上長骨刺的頭犬會嚎叫標記你，站在你前面盯著，其他幾隻繞到背後咬。把頭犬打到重傷，整群就會逃走；背靠牆或隊友背對背，牠們就咬不到。
   - **蛛網織者**：在門口和走廊結黏網，躲在旁邊的暗處。撞進網會被黏住（狂按 E），牠會吐絲把你拖過去咬。網在提燈下會反光；用火打牠會連網一起燒掉，而且傷害加倍；牠拖人時打牠，絲就斷了。
   - **盾甲騎士**（大型）：扛著一整扇鐵門當盾牌的巨人，正面的子彈全被擋下（噹！）。看到直線上的你就蓄力直線衝鋒。繞到側面或背後打牠沒有護甲的背；或站在牆前，最後一刻閃開讓牠撞牆，牠會暈頭、盾牌垂下。
   - **影子跟蹤者**：在黑暗裡看不見（只有一點扭曲的影子），子彈會穿過去。一被提燈或燈光照到就定住、變成實體，這時才打得痛。牠只從背後下手：倒退走，用燈照著牠。
   - **窺視眼**（小型，2～4 隻）：長翅膀的眼球，在你頭上盤旋，每隔幾秒尖叫報出你的位置（其他怪物和守墓者都聽得到），偶爾俯衝撞你的臉。很脆弱，電擊、暈眩會讓牠掉到地上；你瞄準時牠會亂閃，等牠俯衝再打。躲出牠的視線牠就跟丟了。
   - **噴吐者**：駝背長腿、喉嚨腫成一顆發綠光的酸囊。永遠保持一個房間的距離，拋出酸液，地上會留下燒腳的綠色水窪。打中喉囊傷害三倍（蓄力時囊最大最好打），受傷它就會逃走。
   - **鐵甲穿山者**（大型）：貨車大的鐵甲穿山甲，在地板底下游，比你衝刺還快，地上會看到一道隆起的裂磚在移動。它只聽得到一樓地面的聲音，會從發出聲音的人腳下衝出來，然後立起身往前壓。背上的鐵甲子彈打不進去，只有它立起來時露出的肚子打得痛。爬到桌子、走道、樓梯上，或蹲著走，它就聽不到你。
   - **分裂者**：好幾個身體黏成一團，慢慢跟著你。用子彈打死它，它會裂成 2～3 隻跑很快的小爬蟲；用火（或爆炸）打死它就不會分裂。小爬蟲一分鐘後會自己餓死。
   - **吊頂者**：攀在暗處天花板上的灰色長影，有人從下面經過就掉下來，打掉提燈、把人拖進黑暗，沒人救就拉上天花板。提燈亮著它就不敢下來；被抓住時按 F 重新點燈、隊友用燈照它、或用火燒它，它就會放手。
   - **尖叫面具**（小型）：披著破布的白色瓷面具，本身不會傷人，但一看到你就深吸一口氣放聲尖叫，整張地圖的怪物都會趕過來。槍口對著它它就叫不出來、只會逃；很脆弱，趁它吸氣時一槍打掉。
   - 怪物被打時各有反應：假人被人看著時打不動、霧行者沒現形時子彈會穿過去、擬態蟲死前會尖叫、迎賓員不准你在店裡開槍、調音師會習慣同一種打法、巨像排氣時最脆弱，大型怪物打不死，只會被打倒一陣子。
4. **鍋爐巨像**（大型）：兩層樓高的蒸氣機械，被抓到就死。
   - 它聽得到腳步聲、落地聲、吵鬧的物品；衝刺最吵，蹲著走最安靜。
   - 開著提燈它在 26 公尺外就看得到你，關燈只剩 8 公尺。
   - 它進不了通風管道、窄門小房間，也上不了高架走道和管線。
   - 每 40 秒左右它必須排氣 5 秒，這時它看不見也聽不到，碰到也不會死。
5. **撤離**：出口要先完成地圖的目標才有電（工廠是重啟主鍋爐），但完成時的巨響會吵醒整張地圖，巨像會直接衝過去而且變快。站在出口裡 4 秒就撤離成功。
6. **時間限制**：15 分鐘後就結束（工廠鍋爐爆炸、商場完全封閉、地鐵站關閉），還在裡面就死了。

物品標籤：**易碎**（從高處摔下來會掉價）、**吵鬧**（拿著會一直發出聲音）、**燙手**（拿著會慢慢扣血）、**重物**、**活的**、**詛咒**、**音樂**、**冰冷**。湊齊一雙襪子、三隻塑膠恐龍、霓虹字母 OPEN 有額外獎勵。刮刮樂要撤離後才知道中多少（$1 到 $5,000）。

scripts/guardian/           守墓者：field_control.gd（能量與三個能力）、guardian_view.gd（機房畫面）、director.gd（AI 導演）

scripts/player.gd           第一人稱玩家（移動、蹲、體力、背包）
scripts/maps/               地圖：game_map.gd（共用規格）、map_roster.gd（每局抽地圖）、midnight_mall.gd、subway_station.gd（廢棄地鐵站）、endless_afternoon.gd（夢核）、dream_door.gd
                            room_grid.gd（隨機延伸的房間）、room_kits.gd / facility_kits.gd（房間與設施）、props.gd（低多邊形家具與雜物）
scripts/traps/              陷阱：traps.gd（種類與生成）和每種陷阱

scripts/boiler_factory.gd   鍋爐工廠場景（用程式碼生成，含導航網格）
scripts/monsters/           怪物（鍋爐巨像、長頸觀察者、蜈蚣列車、哄睡的母親、假人、迎賓員、回收員、霧行者、調音師、撲燈蛾、擬態蟲、發條鼠群、捉迷藏的孩子、噴吐者、鐵甲穿山者、分裂者、吊頂者、尖叫面具等）；monster_roster.gd 決定每局出哪些
scripts/loot_item.gd / loot_table.gd  物品與掉落表
scripts/gear.gd / game_state.gd       進場道具、金錢與存檔
scripts/game_noise.gd       聲音系統（怪物靠它聽到玩家）
scripts/extraction_zone.gd / boiler_lever.gd / locker.gd / ladder.gd  場景互動物件
scripts/hud.gd              遊戲中介面（按住 F1 看操作說明）
shaders/ps1.gdshader        PS1 表面著色器
shaders/ps1_post.gdshader   全畫面後製
textures/                   由 tools/gen_textures.py 產生的 64×64 貼圖
sounds/                     由 tools/gen_sounds.py 合成的低取樣率音效
